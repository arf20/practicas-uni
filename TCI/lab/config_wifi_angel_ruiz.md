# Configuración del router WiFi doméstico - Angel

## Parámetros básicos

 - SSID: ARFNET_5
 - Estandar: 802.11ac
 - Modo: Master
 - Frecuencia: 5.2 GHz
 - MAC de Punto de acceso: 34:60:F9:6E:7A:2D
 - Bit rate: 866.7Mb/s
 - Potencia de transmisión: 16dBm
 - RTS thr: off
 - Fragment thr: off
 - Power management: off
 - Canal: 40
 - Seguridad: WPA3
 - SSID difusion: Broadcast

## Metodo para acceder a la información

 - ssh wap.int.arf20.com
 - iwconfig
